INSTALACIÓN
1. Descomprimir el ZIP en la raíz de scardozoprogramming.github.io respetando las carpetas.
2. Reemplazar los archivos que coincidan; no borrar archivos del proyecto existente.
3. Abrir Websites/PortafolioFisioNatalia/portafolionatalia.html y comprobar visualización.
4. Para el iframe de la web real, se requiere conexión. Carga solo al pulsar "Cargar web interactiva". Si el navegador no permite integrar la web, hay enlaces directos.
5. Publicar con Git solo cuando se haya probado en el entorno local.
