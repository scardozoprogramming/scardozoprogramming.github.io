Una llamada, una decisión

Acordad las palabras antes de jugar y usadlas pronto. Abre cada llamada para ver cómo debe responder tu pareja.

Para empezar: «Mía» decide quién recibe; «Tuya» deja el balón al compañero.

Antes de cada punto

  1. Mirad a vuestro compañero.
  2. Acordad la señal de bloqueo o defensa.
  3. Elegid el objetivo de saque.
  4. Confirmadlo en voz alta.
  5. Respirad y jugad.
