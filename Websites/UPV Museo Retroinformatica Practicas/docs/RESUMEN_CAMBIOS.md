# Versión definitiva — Cambios entregados

- Se mantiene la estética institucional retro ya aprobada: fondo oscuro, crema, amarillo y acentos discretos.
- Las cuatro imágenes de Arcade, Amstrad CPC 464, Commodore 64 y ZX Spectrum son los **mismos archivos** en Inicio, Máquinas y sus ventanas de ficha.
- MSX y Atari 2600 conservan sus ilustraciones SVG, al no aparecer en la portada.
- Los recursos se ordenaron por función: `assets/css/`, `assets/js/`, `assets/img/brand/`, `assets/img/machines/`, `assets/img/editorial/`, `assets/img/sprites/`, `assets/img/ui/`.
- Se unificaron las hojas de estilo; se retiraron imágenes y scripts no usados.
- Se eliminaron las referencias al estado de aprobación y a las revisiones pendientes.
- Se conservó la carpeta `retroinformatica_prototipo_v1_1` para que las URL actuales de GitHub Pages no cambien.
- Se añadió `index.html` para abrir el Inicio desde la carpeta.
- Se conservaron los filtros, los cuadros informativos, la navegación móvil y la validación visual del formulario.

**Limitación real de datos:** la web no incluye un sistema de envíos para el formulario ni inventa fechas, disponibilidad, catálogo oficial o avisos legales. Estos datos deben completarse con la información del club antes de activar dichas funciones.
